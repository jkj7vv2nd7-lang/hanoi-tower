# ハノイの塔 シミュレーター＆工作キット

実物らしく動くハノイの塔シミュレーターと、厚紙で実物を作るペーパークラフトキットの2部構成。単体HTMLアプリ（自己完結・CDN不使用）。

## ファイル
- `index.html` — アプリ本体（シミュレーター＋記録表＋型紙7ページ＋印刷用画像の書き出し）
- `icon.png` / `icon-180.png` — ホーム画面アイコン（自作描画）
- `verify.js` — 自動検証（起動・幾何・マウス操作の実演・ソルバー・PNG実寸）
- `shot.js` — プレビュー画像の生成（確認用）

## 第1部 シミュレーター
- 見た目：木目の土台・柱・円盤（大きさごとに木の色味を変え、上面の楕円と木目線、柔らかい影、高さで薄くなる影で立体感を表現）
- 操作感（最重要要件）：
  - 円盤を指／マウスで直接つかむ。つかんだ円盤はまず柱に沿って真上に抜け（柱の上端を越えるまで横に動かない実物の制約を再現）、その後ついてくる
  - 柱の上で離すと柱に沿って降りて積み重なる。関係ない場所で離すと元の位置へ滑って戻る
  - 動きはバネ物理（加速・減速）。着地はわずかに行き過ぎてから「コトン」と静止する沈み込み表現。運搬中は移動方向へ最大約4°傾く。大きい円盤ほどバネを弱くして重くゆっくり
  - 置けない場所（小さい円盤の上）で離すと、小さく揺れて受け付けず元の場所へ戻る
- 音：着地時の木の音をWeb Audioで合成（円盤が大きいほど低い音、控えめな音量、ミュート切替つき）。完成時は静かな2音のチャイム
- 機能：手数カウント、取り消し（アニメーション付きで1手戻る）、リセット、円盤3〜8枚切替、完成判定と静かな祝福表示、最短手順の自動再生（最初から再生、速度4段階。再帰の手順パターンが見える）
- 発見の仕掛け：枚数1〜8の最短手数表（1, 3, 7, 15, 31, 63, 127, 255）と自分のベスト記録（端末内に保存。自動再生を使った完成はベストに入らない）、「2倍＋1」の理由の解説、2ⁿ−1への一般化、64枚の伝説（約5,850億年）

## 第2部 ペーパークラフトキット（型紙7ページ）
- 型紙1〜3：円盤6枚（直径120/110/100/90/80/70mm、色分け、中心穴12mmの目印つき）
- 型紙4：柱（三角柱の展開図×3、高さ80mm、折り線・のりしろ・土台貼りフラップつき）、土台70mm角×3（柱位置の三角目印つき）、ふたの三角×3
- 記録表：日付・枚数・回数・最短・ちがいの記録欄と、2ⁿ−1への気づきを促す問いかけ
- 説明書1・2：組み立て手順、遊び方、記録のつけ方、問いかけ
- 印刷はいつもの方式（アプリが各ページをA4実寸300dpi画像として書き出し、赤い5cm較正線つき）。土台は中心間隔約13cmで机に並べて使う

## 検証済み（verify.js 全項目合格）
- 起動・ページエラー0、キット幾何＋ソルバー38項目（円盤の直径、全ページの収納・非重なり、較正線50mm、ソルバーの全手合法性と手数）
- マウス操作の実演検証：つかんで真上に抜く間の横位置のずれ0.0（柱に沿ってのみ上昇）、運搬→柱の上での着地と手数カウント、無関係な場所で離すと復帰、置けない配置では揺れ（shake）を確認して復帰・手数不変、取り消しで盤面と手数が復元、手動完成でベスト記録、自動再生で3枚を最短7手で完成（ベストには入らない）、8枚への切替、音の切替
- 型紙PNGの実測：較正線596px、円盤（大）の直径120.31mm（線幅を含む実測で実寸どおり）
